# Dax the Traveler — Canva Assets

Drop exported Canva files here. Supported: PNG, JPG, PDF.

## Naming convention
  cuba-hero-banner.jpg
  puerto-rico-trip-card.png
  dax-travel-kit-cover.jpg
  passport-pieces-grid.png

## After adding files, update canva-manifest.json:
{
  "filename": "cuba-hero-banner.jpg",
  "label": "Cuba Hero Banner",
  "type": "banner",
  "use": "hero"
}

## Asset types
- banner      → hero/header graphics
- trip-card   → per-destination story cards
- thumbnail   → YouTube/vlog thumbnails
- social      → Instagram/TikTok post graphics
- resource    → travel kit / gear guide covers
