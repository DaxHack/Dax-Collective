## Evidence rules

- CONFIRMED: Daniel explicitly supplied the fact, or it is supported by inspected media/records. First-person confirmation is not described as independently verified flight evidence.
- APPROXIMATE: remembered period, duration, or relationship, without established exact dates.
- UNKNOWN: not yet verified; never proof that a trip did not happen.
- Date-like filenames are candidate clues, not confirmation of a photograph’s location, trip, or capture date.
- Generic brand-library imagery is not evidence that Daniel visited its subject.
- Use photo/video/story/cost/itinerary/recommendation controls only for content that really exists.
- Never alter originals. Browser derivatives, if approved later, must be separate files with source references.
