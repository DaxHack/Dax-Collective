# God's Vessel — Canva Assets

Drop exported Canva files here. Supported: PNG, JPG, PDF.

## Naming convention
  001-el-shaddai-hoodie-mockup.png
  002-adonai-study-card.png
  hero-names-of-god-banner.jpg
  waitlist-cta-graphic.png

## After adding files, update canva-manifest.json:
{
  "filename": "001-el-shaddai-hoodie-mockup.png",
  "label": "El Shaddai Hoodie Mockup — Archive No. 001",
  "type": "product",
  "use": "hero"
}

## Asset types
- product     → hoodie/tee/card mockups
- banner      → hero/header graphics
- social      → Instagram/TikTok post graphics
- thumbnail   → YouTube/video thumbnails
- print       → print-ready files (PDF)
