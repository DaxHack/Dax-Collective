## Script

**Hook (0-4s)**
What if Return by Death is not Subaru's advantage? What if it is the story's harshest interrogation room?

**Angle (4-10s)**

**Viewer value (16-23s)**

**Close (23-30s)**
Ani-Dax takeaway: the ability is not interesting because it beats death. It is interesting because it makes survival emotionally expensive.
