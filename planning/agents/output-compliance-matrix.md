# Output Compliance Matrix

This matrix converts the previous planning requirements into agent checks.

## Global Checks

All agents must:

- keep publishing disabled until account credentials and review gates are approved
- avoid reading, printing, copying, or storing secrets
- create outputs with `manual_review_required` by default
- identify brand, platform, output type, CTA, assets needed, and review status
- route failures to the Error Handler Agent

## Posts

Responsible agents:

- Social Post Agent
- Content Strategy Agent
- Compliance and QA Agent

Required checks:

- brand voice matches the platform and brand blueprint
- post type is identified: caption, carousel, community post, short update, launch post, product post
- CTA is platform-appropriate
- hashtags are brand/platform relevant
- claims are not exaggerated or unsupported
- output ends as `manual_review_required`

## Videos

Responsible agents:

- Video Concept Agent
- brand-specific Video Agent
- Scriptwriting Agent
- Video Production Agent
- Compliance and QA Agent

Required checks:

- hook appears in the first 3 seconds
- script, scene plan, CTA, tags, description, and thumbnail brief are present
- video package is review-only
- no automatic upload
- platform-specific aspect ratio is identified
- copyright risks are flagged

## Itineraries

Responsible agents:

- Itinerary Agent
- Dax the Traveler Video Agent
- Time-Zone Travelers Video Agent
- Compliance and QA Agent

Required checks:

- destination, duration, budget tier, audience, and season are identified
- prices, hours, routes, weather, visa/legal, and safety facts are flagged for current verification
- estimates are labeled as estimates
- safety notes are included
- affiliate recommendations are marked as optional

## Merch

Responsible agents:

- Merch Design Agent
- Brand Design Agent
- Revenue Agent
- Compliance and QA Agent

Required checks:

- design is original and ownable
- print format is identified: tee, hoodie, patch, hang tag, banner, product mockup
- file targets are identified: transparent PNG, SVG/vector, print PDF, mockup image
- brand lane is clear, especially God's Vessel premium faith label vs urban faith streetwear
- no copied logos, characters, brand marks, or derivative protected art
- production notes include color, placement, and safe margins

## Stickers

Responsible agents:

- Sticker Design Agent
- Brand Design Agent
- Asset Management Agent
- Compliance and QA Agent

Required checks:

- sticker is readable at small size
- transparent background requirement is stated
- cutline and bleed/safe margin notes are present
- no derivative protected characters, logos, or marks
- pack theme and individual sticker names are included

## Designs

Responsible agents:

- Brand Design Agent
- Asset Management Agent
- Compliance and QA Agent

Required checks:

- no generic globe icons or random clipart
- sub-brand mark has a distinct silhouette from the parent mark
- no copying the parent lion mark for sub-brands
- no derivative copies of known brands
- thumbnail design includes big readable text, strong focal image, brand color accent, and consistent template rules
- Ani-Dax avoids unlicensed screenshots and uses original or approved art references
