# Daniel / travel originals

This is a local, non-public intake area. Drop original photos into the relevant folders without renaming or replacing existing files. Files here are not automatically published.

Use `Daniel/Portraits/` for personal images whose destination is not established, and `Travel/<destination>/` for images whose association Daniel can verify. Full instructions and current asset observations: `docs/DAX-TRAVEL-ASSET-INTAKE.md`.

Originals must stay unchanged. A file date alone is not proof of location. Browser derivatives and publication require deliberate review. HEIC originals can remain here even when they are not browser-displayable.
