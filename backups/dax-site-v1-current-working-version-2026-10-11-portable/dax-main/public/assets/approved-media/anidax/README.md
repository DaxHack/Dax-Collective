# Approved Media — AniDax

This folder stores manually-approved photo and video assets for the **AniDax** brand.

## What belongs here

- Original artwork, illustrations, or designs created for AniDax content
- Photography of physical anime merchandise owned by the brand (figures, books, Blu-rays)
- Desk/setup shots used for AniDax editorial content
- Event or convention photography where subjects have consented

## Naming convention

```
[content-type]-[series-ref]-[short-description].[ext]
```

Examples:
- `editorial-rezero-desk-setup.jpg`
- `merchandise-jjk-figure-display.jpg`
- `setup-anidax-recording-space.jpg`

## Privacy rules

- **Do not place copyrighted anime artwork, screenshots, or promotional materials here.** AniDax operates under fair use for written commentary — images are not covered.
- No photos of convention attendees without consent
- Assets must be set to `usageStatus: "Approved"` and `privacyStatus: "Public Safe"` in `approvedMedia.js`

## Content series tags

Use one of these `relatedSeries` values:

- `Anime Files`
- `AniDax Pulse`
- `Character Files`
