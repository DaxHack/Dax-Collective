# Draft Suggestions Log

This folder holds per-season draft anime-image suggestions before any of them are reviewed into `ANIME_IMAGE_SOURCE_REGISTRY.md`.

Naming convention: `[year]-[season]-draft.md`, e.g. `2026-summer-draft.md`.

Each file should list candidate titles/images pulled from AniList (or another approved official source) for that season, each with a proposed row matching the main registry's columns, all starting at `approval_status: draft_suggestion`. Nothing in a draft file is live or approved until you review it and copy/promote the row into the main registry with an explicit `approval_status: approved` and a deliberately chosen `allowed_use`.

No draft files exist yet — the first one will be created the next time a seasonal anime fetch/review happens.
