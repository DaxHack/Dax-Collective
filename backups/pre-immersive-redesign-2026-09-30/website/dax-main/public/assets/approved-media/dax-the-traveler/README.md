# Approved Media — Dax the Traveler

This folder stores manually-approved photo and video assets for the **Dax the Traveler** brand.

## What belongs here

- Travel photos taken by or featuring Dax on documented trips
- Behind-the-scenes stills from vlog shoots
- Destination landscape/scene shots where no privacy-sensitive subjects appear
- Gear and kit shots (camera bags, packing setups, etc.)

## Naming convention

```
[year]-[destination]-[short-description].[ext]
```

Examples:
- `2024-puerto-rico-old-san-juan-street.jpg`
- `2024-cuba-havana-plaza-wide.jpg`
- `2023-atlanta-packing-setup.jpg`

## Privacy rules

- **Never place files here** if they show identifiable people who have not given consent
- All assets in this folder must be set to `usageStatus: "Approved"` and `privacyStatus: "Public Safe"` in `approvedMedia.js` before the site will display them
- Do not drop raw unreviewed exports here; use a staging subfolder or Admin Studio's Media Intake tab first

## Content series tags

Assets should be tagged with one of the following `relatedSeries` values to appear in the correct section on the Dax the Traveler page:

- `From the Vlog`
- `Quick Blips`
- `Wanderlost with Dax`
- `Dax Travel Kit`
- `Seen in the Vlog`
- `Quick Jumps`
