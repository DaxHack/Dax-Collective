# Approved Media — Time-Zone Travelers

This folder stores manually-approved photo and video assets for the **Time-Zone Travelers** brand.

## What belongs here

- Destination photography used for zone guides and travel dispatches
- Infographic-style images (packing lists, itinerary illustrations)
- Airport, transit, and logistics photography
- City and landmark shots aligned with SEO travel content

## Naming convention

```
[year]-[destination]-[content-type]-[short-description].[ext]
```

Examples:
- `2024-tokyo-zone-guide-shibuya.jpg`
- `2024-paris-weekend-eiffel-tower.jpg`
- `2024-general-airport-security-tips.jpg`

## Privacy rules

- Assets must be set to `usageStatus: "Approved"` and `privacyStatus: "Public Safe"` in `approvedMedia.js` before appearing on the site
- No street photography containing identifiable faces without consent
- All location claims in file names must match the actual depicted location

## Content series tags

Use one of these `relatedSeries` values:

- `Zone Guides`
- `Travel Dispatches`
- `Time-Zone Tips`
